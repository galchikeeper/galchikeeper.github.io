# f45-pipeline

f45-pipeline은 galchikeeper가 혼자 쓰는 개인용 사진 정리 도구입니다. 본인 Google Drive에 올린 F45 SINSA 수업 사진을 정리하고, 기본 보정과 로고를 넣어 다시 본인 Google Drive에 저장합니다.

f45-pipeline is a personal tool used only by its owner (galchikeeper). It organizes class photos in the owner's own Google Drive, applies light edits and a logo, and saves the results back to the owner's Google Drive.
